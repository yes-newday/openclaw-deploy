为什么选择腾讯云？

  • ✅ 香港/新加坡节点，国内访问快
  • ✅ 无需备案即可使用
  • ✅ 支持国际 AI API 直连
  • ✅ 一键安装镜像

部署步骤

1访问腾讯云开发者实验室

打开腾讯云 OpenClaw 一键部署页面：

https://cloud.tencent.com/developer/article/2624973

2购买轻量服务器

选择配置：

  • 香港区 - 推荐，延迟低，无需备案
  • 新加坡区 - 东南亚访问好
  • 推荐 2核2G 以上配置

3SSH 登录服务器

使用终端连接服务器：

ssh root@你的服务器IP

4运行安装脚本

腾讯云提供了预装镜像，直接运行：

curl -fsSL https://openclaw.ai/install.sh | bash

或使用一键部署命令：

openclaw onboard

5配置 API Key

按提示输入 API Key，可选平台：

  • 硅基流动 - https://cloud.siliconflow.cn
  • DeepSeek - https://platform.deepseek.com
  • OpenAI / Anthropic（需要代理）

6配置防火墙

在腾讯云控制台安全组添加规则：

  • TCP 18789 - OpenClaw 网关
  • TCP 22 - SSH

获取 API Key

推荐使用国内 API 提供商：

1. 硅基流动

https://cloud.siliconflow.cn

新用户送免费额度，支持 Qwen、DeepSeek 等模型

2. DeepSeek API

https://platform.deepseek.com

性价比高，API 稳定

3. 腾讯云混元

腾讯自家大模型，新用户有免费额度

⚠️ 注意事项
  • 香港服务器无需备案，但要注意流量
  • 2G 内存可能不够，建议创建 Swap
  • 记得开放 18789 端口
✅ 部署完成

访问方式：

  • Web: http://服务器IP:18789
  • Telegram/飞书/钉钉 发送消息即可

常用命令

# 查看状态
openclaw status

# 重启服务
openclaw restart

# 更新版本
openclaw update

# 查看日志
openclaw logs
