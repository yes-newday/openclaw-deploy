🎯 新手必备技能

OpenClaw 热门 Skills 推荐及安装命令

💡 什么是 Skills？

Skills（技能）是 OpenClaw 的扩展功能，可以让你的 AI 助手具备各种能力，如搜索、编程、文件处理等。通过安装不同的 Skills，你可以定制化你的 OpenClaw。

安装方式

方式一：命令行安装

# 安装单个 Skill
openclaw skill install 技能名

# 查看可用技能列表
openclaw skill list

# 更新所有技能
openclaw skill update

方式二：提示词安装

直接发送安装提示词给 OpenClaw：

请帮我安装 [技能名] 技能

🔥 必备技能（强烈推荐）

🔍
Web Search
联网搜索能力，可以实时获取互联网上的最新信息
openclaw skill install web-search
📝
Fetch
网页内容抓取，可以获取任意网页的完整内容
openclaw skill install fetch
🖥️
Bash
执行终端命令，在服务器上运行各种命令行工具
openclaw skill install bash
📁
Read Files
文件读取，支持读取各种格式的文件内容
openclaw skill install read-files
🌐
Browser
浏览器控制，可以自动化操作网页
openclaw skill install browser
📋
Clipboard
剪贴板管理，读取和写入系统剪贴板
openclaw skill install clipboard

⚡ 效率提升技能

📊
PDF
PDF 处理，提取、转换、生成 PDF 文件
openclaw skill install pdf
🖼️
Image
图像处理，图片识别、转换、编辑
openclaw skill install image
📧
Email
邮件管理，发送和接收电子邮件
openclaw skill install email
📅
Calendar
日历管理，创建和管理日程提醒
openclaw skill install calendar

💻 开发技能

🐙
Git
Git 版本控制，提交、推送、拉取代码
openclaw skill install git
🐳
Docker
Docker 管理，容器操作和镜像管理
openclaw skill install docker
☁️
Cloudflare
Cloudflare 管理，DNS、Pages、Workers
openclaw skill install cloudflare
📦
NPM
npm 包管理，安装和管理 Node.js 包
openclaw skill install npm

🤖 AI 增强技能

🎨
DALL-E
AI 绘画，生成图片和艺术作品
openclaw skill install dalle
🎬
Video
视频处理，下载、转换、编辑视频
openclaw skill install video
🔊
TTS
文字转语音，生成语音输出
openclaw skill install tts
🎙️
Whisper
语音转文字，音频视频字幕生成

openclaw skill install bash

openclaw skill install browser

或者直接告诉 OpenClaw：

请帮我安装所有必备技能
