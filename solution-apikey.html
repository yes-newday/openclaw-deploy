配置步骤

1. 获取 API Key

以硅基流动为例：

  1. 访问 cloud.siliconflow.cn
  2. 注册/登录账号
  3. 进入「API 密钥」页面
  4. 点击「新建密钥」
  5. 复制生成的 Key

2. 配置 OpenClaw

# 方式1: 交互式配置
openclaw config
# 方式2: 直接编辑配置
nano ~/.openclaw/openclaw.json
# 配置示例
{
  "models": {
    "default": {
      "provider": "siliconflow",
      "model": "Qwen/Qwen2.5-7B-Instruct",
      "apiKey": "sk-xxxxxxxxxxxx"
    }
  }
}

验证配置

# 测试 API 连接
openclaw test

# 或查看日志
openclaw logs

常见问题

Q: API Key 无效？

检查 Key 是否复制完整，不要有空格或换行

Q: 额度用完了？

登录对应平台充值或换用其他免费平台

Q: 模型不支持？

使用平台支持的模型名称，可参考平台文档
