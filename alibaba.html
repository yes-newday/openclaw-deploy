部署步骤

1访问阿里云控制台

https://www.aliyun.com/activity/ecs/clawdbot

2选择配置

  • ¥168/年 - 2核2G，带宽5Mbps，推荐日常使用

3购买并创建服务器

完成支付后，阿里云会自动创建 OpenClaw 镜像的服务器。

4配置安全组

在阿里云控制台添加安全组规则：

  • TCP 18789 端口 - OpenClaw 网关端口
  • TCP 22 端口 - SSH 远程登录

5初始化 OpenClaw

通过 SSH 连接服务器后，运行初始化命令：

按照提示完成：

  • 输入 API Key（推荐硅基流动或 DeepSeek）

常见问题

Q: 服务器内存不足怎么办？

创建 Swap 虚拟内存：

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

Q: 如何更新 OpenClaw？

openclaw update

Q: 怎么查看运行状态？

openclaw status
