飞书机器人接入 OpenClaw

将 OpenClaw 接入飞书，实现智能助手功能

前置要求

  • ✅ 已部署完成的 OpenClaw 服务器
  • ✅ 飞书企业管理员账号
  • ✅ 有效的 API Key

部署步骤

1创建飞书企业应用

1. 打开 飞书开放平台

2. 点击「创建企业应用」

3. 填写应用名称（如 OpenClaw 助手）

4. 获取 App ID 和 App Secret

2配置应用权限

在飞书开放平台后台，进入「权限管理」，添加以下权限：

  • im:chat:readonly - 查看群信息
  • im:message:send_as_bot - 以机器人身份发消息
  • im:message:receive - 接收消息
  • im:chatMembers:readonly - 查看群成员

3发布应用版本

1. 进入「版本管理与发布」

2. 创建新版本

3. 添加可用权限

4. 发布上线

4配置 Webhook

1. 在飞书开放平台创建「自定义机器人」

2. 获取 Webhook 地址

Webhook 格式类似：

https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

5在 OpenClaw 中配置飞书

编辑配置文件 ~/.openclaw/openclaw.json：

{
  "channels": {
    "feishu": {
      "enabled": true,
      "webhook": "你的Webhook地址"
    }
  }
}

或使用命令行：

openclaw config set channels.feishu.enabled true
openclaw config set channels.feishu.webhook "你的Webhook地址"

6重启服务

openclaw restart

高级配置

配置加密密钥（可选）

{
  "channels": {
    "feishu": {
      "enabled": true,
      "webhook": "你的Webhook地址",
      "encrypt_key": "你的加密密钥",
      "signing_secret": "你的签名密钥"
    }
  }
}

配置代理（如果服务器在国内需要访问国际 API）

{
  "channels": {
    "feishu": {
      "enabled": true,
      "webhook": "你的Webhook地址"
    }
  },
  "proxy": {
    "url": "http://127.0.0.1:7890"
  }
}

常见问题

Q: 收不到消息？

  • 检查 Webhook 地址是否正确
  • 确认应用已发布上线
  • 检查权限是否添加完整

Q: 消息发送失败？

  • 确认 im:message:send_as_bot 权限
  • 检查应用是否在对应群聊中

Q: 如何 @机器人？

在群聊中 @机器人 并发送消息即可
